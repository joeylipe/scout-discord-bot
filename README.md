# Scout 🐻

Scout is a personal Discord bot built with Python and [discord.py](https://discordpy.readthedocs.io/).

The goal of Scout is to monitor useful information and automatically notify Discord servers when something worth knowing about appears.

## 🎮 Free Games

Scout's first major feature is free-game monitoring across multiple PC game stores.

Planned functionality includes:

* Epic Games free-game monitoring
* Steam free-game monitoring
* GOG free-game monitoring
* Automatic free-game notifications
* Manual checks when needed

## 🚧 Project Status

Scout is currently in active development.

The project is being built incrementally, with features tested locally before being deployed for long-term use.

## 🛠️ Built With

* Python
* discord.py
* Git / GitHub

## 📌 Current Status

Scout is currently connected to a private Discord test server.
